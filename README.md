# NftSilica

NftSilica enables cross-platform, real-time data synchronization through auto-scaling hubs, acting as a decentralized gateway.

The key benefits of using NftSilica include:

- NftSilica enables cross-platform, real-time data
- synchronization through auto-scaling hubs, acting
- as a decentralized gateway

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftSilica.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NftSilica is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
